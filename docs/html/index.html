Critical Simulation Role

Authority monitorIndependent checks active

A plausible waveform can still support the wrong engineering decision.

Bounded-Authority-Based-Circuit-Simulation keeps the method that proposes a timestep separate from the independent calculation that decides whether the timestep is trustworthy.

  • Events: reach commanded switching times exactly, rather than crossing them inside one timestep, which is one advance in simulated time.
  • Nonlinear solves: expose whether iterative device equations converged.
  • Long runs: separate timing drift from stored-energy drift.
  • Delivery: verify that source code and the installed package produce equivalent evidence.
