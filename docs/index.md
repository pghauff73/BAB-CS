# BAB-CS Documentation

BAB-CS (Bounded Adams–Bashforth Circuit Simulation) combines candidate
integrators with projection, independent reference authority, contractive
correction, runtime gates, and periodic replay. Its reported bound applies to
the implemented numerical error model rather than an unknown exact physical
trajectory.
